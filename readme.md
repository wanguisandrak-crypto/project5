# Lex's Art Photography

A simple photography gallery celebrating the beauty of nature. Created by Lex, a young photographer from Nairobi, Kenya, who enjoys seeing the world through a creative lens.

## About the gallery

The page features nature imagery with captions, including Mount Kenya, Ouzoud Waterfalls, and the Indian Ocean.

## View the website

Open `index.html` in a web browser. This is a static HTML and CSS project, so no installation or build step is required. An internet connection is needed to load the images, which are currently embedded from external image URLs.

## Project files

- `index.html` — page content and image gallery
- `style.css` — gallery styling
